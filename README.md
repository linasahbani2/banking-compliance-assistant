# Banking Compliance & Audit Assistant

Assistant intelligent pour les équipes conformité et audit bancaire, basé sur un pipeline RAG (Retrieval-Augmented Generation).

## Stack technique

- **Frontend** : React + TypeScript
- **Backend** : FastAPI (Python) — API métier + pipeline RAG
- **Base de données** : PostgreSQL + pgvector (via Docker)
- **IA** : LangChain, LlamaIndex, Mistral/Llama
- **DevOps** : Docker, GitHub Actions

## Fonctionnalités

1. Base documentaire intelligente
2. Assistant IA (RAG) — question/réponse sur les documents internes
3. Analyse automatique de conformité
4. Génération automatique de rapports d'audit
5. Risk Dashboard
